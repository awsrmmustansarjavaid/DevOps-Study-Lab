# ⚠️ Important Note

This repository is primarily a **personal study, research, experimentation, and practice environment**.

Not every configuration or example should be considered production-ready.

Before using any configuration in a production environment:

* Review security requirements
* Remove development credentials
* Use appropriate secret management
* Apply least-privilege access
* Review networking rules
* Validate infrastructure changes
* Test configurations in an isolated environment

**No passwords, API keys, access tokens, private keys, or other sensitive credentials should be committed to this repository.**
